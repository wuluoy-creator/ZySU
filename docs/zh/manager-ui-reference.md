# 管理器界面改进对照

参考版本：[FinaSU 67a56dc](https://github.com/LyraVoid/FinaSU/tree/67a56dc2a0a286fa0dec51825611f735f7e5e0d7)，核对日期：2026-11-13。

本轮将参考仓库的界面组织方式应用到 ZySU 已有的管理器功能，保留 ZySU 的品牌、Root 授权与 SUMH 操作语义。主题商店、主题下载和市场接口不在范围内。

| 范围 | FinaSU 参考实现 | ZySU 的实现与补充 |
| --- | --- | --- |
| 首页层级 | `ui/screen/home/HomeStatusCard.kt`、`HomeFactsCards.kt` | 主卡片、KSUD、SUMH 共用标题、版本／协议详情和状态行的排版，组成上部布局。已安装时点击工作状态卡进入安装／升级；未安装、认证操作保留。下方核心信息的 13 个字段可逐项显示／隐藏，全部隐藏时不留空卡片；长字段点击查看完整可复制详情。 |
| 服务卡片 | `HomeMetricComponents.kt`、`HomeCountCards.kt` 的区域组织 | 按当前要求移除系统概览、趋势、授权与模块统计及其显示开关和采集逻辑，原区域改为实际 KSUD、SUMH 卡片。两卡共用标题、版本／协议详情行、状态行和间距，保留同步／刷新行为。 |
| 首页布局 | `HomeLayoutStyle.kt`、`Home*Layout.kt` | 仅保留圆环、网格、聚焦三种。圆环：主卡片下方并列服务卡；网格：左侧一张主卡片，右侧 KSUD、SUMH 上下排列，主卡片与两张服务卡的总高度一致，内部按顶部标题、中部版本、底部状态与操作分布，保留统一文字样式；聚焦：三卡纵向排列，宽屏自适应。大字号和窄屏堆叠，选择即时生效并回到顶部。已删除的仪表盘迁移到圆环，统计迁移到聚焦。 |
| 主卡片图片 | `wallpaper/WallpaperManager.kt`、工作卡片背景配置 | 三种布局共用一张自定义背景，支持普通图片及 PNG／WebP 透明区域，适应／填充、50–300% 缩放、实时预览、更换和移除。覆盖层不透明度可调 0–100%，0% 不遮盖图片、100% 完全覆盖为主题卡片底色；默认 82%，更换图片保留选择。校验后将原始图片复制到应用私有目录，保留透明度；失败时保留旧图片。 |
| 导航样式 | `ui/component/bottombar/FloatingBarDrawer.kt` | 仅保留原玻璃胶囊与玻璃胶囊抽屉。移除 Material、悬浮标准和配套顶栏分支；旧 Material 迁移到玻璃，旧标准迁移到抽屉。抽屉与顶栏共享材质、圆角、外侧间距及中性控件色，保留选中项展开、徽标、安全区与键盘隐藏逻辑。 |
| 应用列表 | `ui/screen/superuser/SuperUserMaterial.kt` | 应用组摘要、全部／已授权／未授权／自定义配置筛选、次级 Android 用户标记；保留共享 UID 提示、批量操作和授权确认。 |
| 模块列表 | `ui/screen/module/ModuleItemCard.kt`、`ModuleSortMenu.kt` | 保留已有模块卡片层级，增加总数／启用／待重启摘要和筛选、名称／ID 排序及方向；明确加载、失败、无匹配和未安装状态；筛选变化回到列表起点。 |
| 设置导航 | `ui/screen/settings/SettingsCategoryContent.kt`、`settings/search/` | 分类保留；搜索可按分类、摘要和功能名找到外观、显示、更新、安全、挂载及诊断入口。多关键词和大小写／重音归一化；结果打开所属分类。 |
| 基础外观 | `ui/screen/colorpalette/`、`ui/screen/font/`、`settings/` | 保留深浅色、动态色、色板和 DPI；提供纯黑背景、系统／衬线／等宽字体及 TTF／OTF 字体导入。导入字体保存到应用内，立即应用并在重启后恢复，可更换、移除或恢复系统字体；损坏文件安全回退。85–130% 应用文字缩放、12–32dp 卡片圆角、预览和重置保留，系统辅助字号继续生效。 |
| 壁纸 | `wallpaper/`、`ui/screen/wallpaper/` | 保留选择、裁剪、更换和移除；增加 Android 12+ 图片模糊；修正透明度、暗度、模糊的持久化和移除后状态同步。 |
| 显示选项 | `HomeDisplaySettings.kt`、`settings/SettingsCategoryContent.kt` | 分为模块信息、主页布局、其他显示设置。隐藏模块标签行归入模块信息；隐藏内核版本号、隐藏链接卡片归入主页布局，原开关偏好继续生效。核心信息可逐项选择。完整移除简洁模式、内核版本简洁模式及其读取和显示分支；旧模式偏好不再影响字段可见性或版本内容。 |
| 交互与可访问性 | 分组行、状态标签、自适应组件 | 状态不只用颜色表示；筛选换行，较多的页签可滚动；选择语义、48dp 触控区域、标题语义和安全区；卡片使用共享主题圆角。 |

参考仓库的其他内核机制、插件运行时、多媒体播放、在线素材、可导入主题包及任意界面素材替换没有作为本轮依赖引入。

参考实现会在部分布局内部安排事实信息；本轮按明确的界面要求，将核心信息固定在 KSUD、SUMH 之后，而只改变其上方区域。这是有意的层级调整，不宣称所有页面与参考仓库逐像素一致。

## 验证

- 与 GitHub 工作流一致的 Gradle 任务：`:app:testDebugUnitTest lintDebug lintRelease assembleRelease -PABI=arm64-v8a`。
- WebUI 桥接回归：`node --test js/tests/webui.test.mjs`。
- 新增回归覆盖数值边界、外观保存与重置、首页偏好实时更新与监听释放、模块筛选和排序、设置搜索。
- `PresentationLayoutTest` 用 Robolectric 原生图形渲染生产组件，验证 375dp 浅色／深色、2 倍字号、800×375dp 横屏的滚动、筛选选择和预览可达性，并输出 `out/fina-ui/` 下的截图。
- `HomeNavigationLayoutTest` 渲染三种实际首页结构、KSUD／SUMH 卡片和导航，检查主卡与服务卡排版一致、卡片随布局重排、字段不重复、长值按需查看，以及安装／认证／详情操作。覆盖中文手机、2 倍字号和横屏。
- `HomeLayoutSettingsTest` 通过真实选择器 → SharedPreferences → 保留的 HomeViewModel → 生产 HomeLayoutContent 验证全部三种选择即时生效及旧选项迁移。`FloatingNavigationLayoutTest` 检查玻璃胶囊与玻璃胶囊抽屉、顶底栏间距、选中项展开、徽标、大字号、RTL 和连续切换。
- `ServiceCardLayoutTest` 检查两张服务卡的标题、详情和状态行对齐、大字号、独立详情操作、加载与协议异常状态，输出 `out/service-card-revision-ui/`。
- 图片测试覆盖原始透明像素保留、私有副本、无效／超大文件保留旧图、缩放实际改变绘制而不影响布局和安装操作，以及设置中的缩放／重置／移除。覆盖层测试验证 0%、中间值、100% 在浅色和深色下的实际像素、持久化、更换图片及写入失败回滚。网格几何断言验证左一右二排列及主卡图片铺满卡片。核心信息测试覆盖逐项选择、全部隐藏、旧简洁模式不再生效和保留 ViewModel 的实时更新。字体测试覆盖导入、字体应用、重新加载、更换、移除和错误回退。
- 本机未连接 Android 实机，截图验证不等同于实机上的 Root、传感器和系统手势测试。

新增文案提供简体中文和英文；其他现有语言按 Android 资源机制回退到英文。
