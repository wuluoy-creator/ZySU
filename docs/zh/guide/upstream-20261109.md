## 本地兼容与补充修正

- UAPI 升为 6。本地 ioctl 22 已用于 `GET_UAPI_VERSION`，因此批量符号查询使用 23；
  保持 `GET_INFO` 为 12 字节、lookup 请求为 24 字节。旧内核仍走 `/proc/kallsyms` 回退。
- ImgPatch 保持 512 字节配置布局，版本升为 4，以 bit 5 表示 `NO_PREINIT`。
  版本 2/3 仍接受各自支持的选项，拒绝无法表达的 `--no-preinit`。
- preinit 使用下一次启动的模块集合，更新目录优先，任一副本的禁用或删除标记均生效。
  状态按模块目录名匹配，避免显示 ID 与目录名不同导致错配。
- metadata 容量核算包含空文件的目录项开销、实际 manifest 大小和临时写入重叠，
  避免大量空文件绕过预算；保留启动失败停用状态，内容变化或手动 reset 后才能解除。
- runner 配置解析修正空行导致提前停止的问题；WebUI 的包信息查询与现有应用扫描
  共用缓存和加载锁，并保留旧包信息接口。
- Linux nolibc 源码作为第三方文件保留，排除在本地自动格式化范围外。

  使用实际编译数据库单独执行 clang-tidy，全部通过。
- kallsyms、启动配置、模块管理和 preinit 主机回归通过；覆盖旧配置兼容、空 token、
  空文件空间边界、复制失败清理、内容更新、禁用状态和启动失败计数。

  exec 失败回退和 bind mount init.rc。实际 ARM64 runner 编译为静态 ELF，
  无解释器及动态段，4 个 LOAD 段均通过 4K/16K/64K 对齐校验。

  0 失败、0 错误、0 跳过。最终 `:app:lintDebug` 为 0 错误、0 警告及 9 条既有提示。
  JS 接口的 7 项测试通过。
