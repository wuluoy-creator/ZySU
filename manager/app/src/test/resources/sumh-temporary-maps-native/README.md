# Production temporary Maps protocol fixtures

These 20 envelopes were generated by the actual C++ temporary Maps callback, client,
inventory/delete serializer and extracted production transport envelope function.
Only the ioctl responses are test doubles. They contain synthetic data.

On Windows, the separate fixture executable force-includes the test-only Android/Linux
errno definitions, with compile-time sentinels. Ordinary host tests keep their host ABI.
For example Android EOPNOTSUPP is 95, while Windows uses 130; Kotlin must not accept
Windows errno values as an Android result. This normalization does not change product code.

Regenerate from repository root:

```sh
python userspace/ksud/tests/run_sumh_host_tests.py --zig <zig> --temporary-maps-fixtures <output-directory>
```

Copy the generated `*-envelope.json` files here after reviewing the producer changes.
`producer-manifest.json` records the Batch30 generating command, input SHA-256 and
both inner and outer artifact hashes; inner callback files remain in the local evidence
directory. The Kotlin integration tests consume these bytes unchanged. This is host
protocol evidence, not Android transport or kernel/device acceptance.
